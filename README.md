# RealWear Assistant

Assistant vocal Android pour RealWear HMT‑1. Il utilise GPT‑Live pour la conversation et peut afficher du texte, des tableaux, des sources et des images générées sur demande. Les commandes WearHF sont numérotées et chaque menu tient sur un écran.

- [Télécharger l’APK de préversion](https://github.com/speccy88/RealWear-Assistant/releases)
- [Guide d’installation, de configuration et de compilation](RealWearAssistant-v1.0.0-preview.1/README.md)
- [Projet Android Studio](RealWearAssistant-v1.0.0-preview.1/)

L’APK exige Android 8.1 ou une version ultérieure. Les sessions OpenAI utilisent une clé API configurée par l’utilisateur. La démonstration fonctionne hors ligne.
